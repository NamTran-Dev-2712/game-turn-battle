# `config/chapters/` — Chương campaign (Phase 34)

Nhóm stage có **thứ tự** tạo chuỗi tiến độ campaign PvE (`order` + `stages[]`). Chuỗi = các chapter theo `order` rồi `stages` theo thứ tự liệt kê; mở khoá **tuần tự** (server-authoritative, chống skip). **Owner:** Game design/level. Schema: `../../shared/config-schema/chapter.schema.json`. Nguồn: `../../docs/gameplay/progression-and-economy.md`. Địch/thưởng/độ khó nằm ở `../stages/` (không đặt balance ở chapter).
