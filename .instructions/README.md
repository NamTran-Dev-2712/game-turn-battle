# `.instructions/` — Chỉ dẫn theo phạm vi

| Mục | Nội dung |
|---|---|
| **Purpose** | Chỉ dẫn ngắn cho AI/dev theo loại task hoặc khu vực (backend/client/config). |
| **Responsibilities** | Bổ sung ngữ cảnh thực thi, **không** thay quy tắc chuẩn. |
| **Allowed** | File `.md` chỉ dẫn theo chủ đề. |
| **Not allowed** | ❌ mâu thuẫn `docs/adr` / `docs/conventions`. |
| **Dependencies** | [`../docs/ai/coding-rules.md`](../docs/ai/coding-rules.md), [`../docs/conventions/`](../docs/conventions/). |
| **Owner** | Từng squad. |
| **Future expansion** | Thêm chỉ dẫn khi rút ra pattern lặp lại. |

## Nội dung
- [`backend.md`](backend.md), [`client.md`](client.md), [`config.md`](config.md), [`combat.md`](combat.md) — chỉ dẫn ngắn theo phạm vi, trỏ về `docs/`.

> Bổ sung ngữ cảnh thực thi; không mâu thuẫn `docs/adr` / `docs/conventions`.
