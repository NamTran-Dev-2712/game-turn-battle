# `.memory/` — Nhật ký quyết định phạm vi dự án

| Mục | Nội dung |
|---|---|
| **Purpose** | Ghi lại quyết định/ngữ cảnh lâu dài **của dự án** để agent/dev nhớ giữa phiên (khác bộ nhớ cá nhân của công cụ AI). |
| **Responsibilities** | Lưu "vì sao" cho quyết định không thuộc tầm ADR nhưng vẫn cần nhớ. |
| **Allowed** | File `.md` ghi chú, mỗi mục một chủ đề. |
| **Not allowed** | ❌ thay thế ADR (quyết định kiến trúc → `docs/adr/`); ❌ secret. |
| **Dependencies** | [`../docs/adr/`](../docs/adr/), [`../docs/mvp/`](../docs/mvp/). |
| **Owner** | Cả team. |
| **Future expansion** | Chuẩn hoá format; liên kết chéo. |

## Nội dung
- [`README-format.md`](README-format.md) — format một mục nhật ký quyết định.
- [`0001-ai-execution-layer.md`](0001-ai-execution-layer.md) — quyết định tách execution layer khỏi docs SSOT.
- [`0002-dev-environment-standardized.md`](0002-dev-environment-standardized.md) — dev env một lệnh (Phase 04): compose Postgres16/Redis7, network `game-team-dev`, profile `api`, `.env`, script up/down đa nền tảng.
- [`0003-shared-contracts-standardized.md`](0003-shared-contracts-standardized.md) — contract spine (Phase 05): `GameTeam.Contracts` là nguồn (enum + DTO nền), OpenAPI sinh từ code ra `shared/contracts/openapi.json` (single-source, CI drift guard), enum ổn định additive-only, `/api/v1`.
- [`0004-config-schema-standardized.md`](0004-config-schema-standardized.md) — config schema (Phase 06): 8 schema per-type + `common.schema.json` + envelope ở `shared/config-schema/` (draft 2020-12, `snake_case`, combat integer, `schema_version`, ID prefix), fixture pass/fail + `_versions/` migration; schema là cấu trúc **không** balance; referential integrity = phase 07.
- [`0005-config-validator-standardized.md`](0005-config-validator-standardized.md) — config validator (Phase 07): `tools/config-validator` (.NET 9, `JsonSchema.Net`) = core lib tái dùng + CLI mỏng + xUnit; kiểm schema + referential integrity (REF001/REF002) + `schema_version` (VER001/VER002); report `file:jsonpath:CODE`; GATE bắt buộc ở `validate-config.yml`; Config Service (phase 21) project-reference core.
- [`0006-codegen-pipeline-standardized.md`](0006-codegen-pipeline-standardized.md) — codegen client (Phase 08): `shared/codegen` (.NET 9, không gói ngoài) sinh GDScript vào `client/src/data/generated/` từ `shared/contracts/openapi.json` (enum giữ số C# qua `x-enum-values`, DTO `Resource`, header DO-NOT-EDIT, deterministic); GATE `codegen-check.yml` (regenerate → `git diff --exit-code`); Godot import sạch; parse = phase 15.
- [`0007-domain-foundation-standardized.md`](0007-domain-foundation-standardized.md) — domain foundation (Phase 09): primitive tái dùng ở `GameTeam.Domain/Common/` (BCL-only, Domain package-free) — `Result`/`Result<T>`, `Error`, `Entity<TId>`, `ValueObject`, `AggregateRoot<TId>` (raise/collect domain event, **không** dispatch), `IDomainEvent`, `IClock` (`DateTimeOffset UtcNow`, ranh giới server-time), `Guard` (**ném** BCL argument exception). Result=lỗi nghiệp vụ mong đợi, exception=lỗi lập trình/hạ tầng; NetArchTest `Domain_should_not_depend_on_framework_packages`; dispatch = phase 10/11.
- [`0008-application-pipeline-standardized.md`](0008-application-pipeline-standardized.md) — application pipeline (Phase 10): 4 MediatR behaviors ở `GameTeam.Application/Behaviors/` thứ tự cố định **`Logging → Validation → Transaction → Caching`** (`PipelineOrderTests` khoá thứ tự); Validation fail → `Result` (`VALIDATION_FAILED`) không ném; Transaction chỉ bao `ITransactionalRequest` (query không vào transaction); Caching chỉ bao `ICacheableQuery` (key = tên+tham số+config version); Logging không log body. Ports `IUnitOfWork`/`IRepository<TEntity,TId>`/`ICacheService`/`IConfigProvider` ở Application (Infra hiện thực 11–12/21), `IClock` dùng lại Domain; command/query mẫu; Application không ref Infra/Api. Deviation nhỏ: `SystemClock` (Infra) cho boot.
- [`0009-persistence-standardized.md`](0009-persistence-standardized.md) — persistence (Phase 11): EF Core 9 + PostgreSQL ở `GameTeam.Infrastructure/Persistence/` (EF/Npgsql CHỈ ở Infra) — `AppDbContext` (override `SaveChangesAsync` dispatch domain event cùng transaction), `EfRepository`/`UnitOfWork` (Commit tự SaveChanges), `DomainEventDispatcher` + `DomainEventNotification<T>`, `schema_metadata` seed v1, migration `Initial`; connection từ config; marker BCL-only `IHasDomainEvents`; Testcontainers `postgres:16-alpine`.
- [`0010-redis-cache-standardized.md`](0010-redis-cache-standardized.md) — redis cache (Phase 12): `ICacheService` hiện thực trên Redis (`RedisCacheService`, StackExchange.Redis) ở `GameTeam.Infrastructure/Caching/` — get/set/**remove** (port mở rộng additive), TTL absolute, key `{env}:{domain}:{name}:{configVersion?}` (`RedisCacheKey`), **graceful degradation** (Redis down ⇒ log warning + degrade, không sập); converter STJ `Result`/`Result<T>` (`Serialization/`, Domain sạch); `IConnectionMultiplexer` singleton (`AbortOnConnectFail=false`), connection từ `ConnectionStrings:Redis`; `/health` ping Redis (ok/degraded, 200); Testcontainers `redis:7-alpine` (CachingBehavior chạy thật, query lần 2 cache hit). Config Service reuse = phase 21.
- [`0011-api-layer-standardized.md`](0011-api-layer-standardized.md) — api layer (Phase 13): `GameTeam.Api` cổng HTTP + composition root — **versioning** Asp.Versioning.Http+Mvc.ApiExplorer 8.1.1 (`/api/v{version:apiVersion}` default v1, `SubstituteApiVersionInUrl`, version set); **xử lý lỗi tập trung** `Api/Http/` (`ErrorHttpMapping` code→status, `ApiResults` `Result`→HTTP+traceId, `GlobalExceptionHandler` unhandled→**500 `ErrorEnvelope`** không lộ stack — MỘT error contract, KHÔNG ProblemDetails); endpoint mẫu qua MediatR (`GET /api/v1/ping`, `GET /api/v1/server-time`+IClock); **Swagger UI** dev-only render OpenAPI first-party (KHÔNG SwaggerGen); auth = hook Phase 18. Deviation: stub Phase 05 giữ literal `/api/v1` (param trùng); `DefaultConfigProvider:IConfigProvider` (Infra config@v1) cho CachingBehavior — thay ở phase 21. `ApiTestFactory` swap port (no-op UoW/cache, FixedClock).
- [`0012-client-autoloads-standardized.md`](0012-client-autoloads-standardized.md) — client core autoloads (Phase 14): hai autoload lõi ở `client/src/core/` (độc lập, single-responsibility, **không** God autoload — ADR-002). **EventBus** (`core/events/event_bus.gd`): pub/sub `emit`/`subscribe`/`unsubscribe`/`is_known`, danh mục **đóng** = hằng `EVENTS` + `signal <name>(payload)` (assert event lạ ⇒ chống "God channel"), tự cleanup qua signal Godot, seed **một** event nền `scene_changed`. **SceneRouter** (`core/scene/scene_router.gd`): `goto_scene`(push)/`back`(pop)/`stack_depth`/`clear_history`, **scene-host thủ công** (tráo tại chỗ, `queue_free` scene cũ ⇒ không rò rỉ — ADR-009), transition tối giản (nâng cao = phase UI), phát `scene_changed` qua EventBus. Đăng ký `[autoload]` trong `client/project.godot`. Bỏ `class_name` (trùng tên singleton) ⇒ dùng global autoload. gdUnit4 11/11 pass (0 orphan). Danh mục event = "hợp đồng nội bộ client".
- [`0013-client-networkclient-standardized.md`](0013-client-networkclient-standardized.md) — client NetworkClient (Phase 15): `NetworkClient` (`core/net/`) là **kênh giao tiếp server DUY NHẤT** (ADR-008/002) — `get_json`/`post_json` (coroutine), base URL env `GAME_TEAM_API_BASE_URL` `/api/v1`, JWT `Bearer` từ `TokenStore` (stub, không log token); seam `HttpTransport`/`GodotHttpTransport` (nơi DUY NHẤT chạm `HTTPRequest` — grep guard); parse JSON→model generated qua `NetworkResponseParser`; lỗi chuẩn hoá `NetResult` + phát `network_error`, 401→thêm `unauthorized`; retry **chỉ GET** (POST không retry); mất mạng→lỗi rõ, không bịa (ADR-011). 21/21 pass.
- [`0015-client-boot-ui-standardized.md`](0015-client-boot-ui-standardized.md) — client boot flow + UI base (Phase 17, **đóng nhóm 3**): app-shell `run/main_scene = src/ui/app_root.tscn` → `SceneRouter.goto(boot)` (router chủ sở hữu mọi screen từ frame đầu). **BootController** (presenter): `/health` = cổng bắt buộc (`parse_health`), `ConfigProvider.check_for_update()` = best-effort (Config Service = phase 21), rồi `SceneRouter.goto(main_hub)` + `clear_history`. **BaseView** (`src/ui/base/`): data-in (`set_data`→`_render`) → intent-out (signal `intent`) + `bind`/`unbind`; **view network-free** (grep guard), presenter là điểm chạm net DUY NHẤT. **User chọn:** intent = signal cục bộ + presenter (KHÔNG thêm event EventBus/nút — danh mục đóng); app-shell (không để boot tự-free). Màn lỗi an toàn + retry (nối một lần, khoá `_running` chống trùng). `AudioManager` HOÃN. gdUnit4 **48/48 pass 0 orphan**; import sạch; smoke scene thật xanh.
- [`0014-client-configprovider-statecache-standardized.md`](0014-client-configprovider-statecache-standardized.md) — client ConfigProvider + StateCache (Phase 16): hai autoload đọc dữ liệu ở `client/src/core/` (sau `NetworkClient`, bỏ `class_name`). **ConfigProvider** (`core/config/config_provider.gd`): cửa đọc config DUY NHẤT — `apply_bundle` cache envelope **BẤT BIẾN** ra `user://config_cache/config@vN.json` (**ghi-một-lần**, ADR-005) + con trỏ `active.json`, boot nạp lại (offline-view), truy vấn data-driven `get_entry`/`get_hero`/`current_version` (bản sao, **không** số hardcode), `check_for_update` qua NetworkClient (endpoint placeholder phase 21/22), phát `config_updated` khi đổi version (áp lại cùng version = no-op). **StateCache** (`core/state/state_cache.gd`): read-cache **CHỈ HIỂN THỊ** (`IS_DISPLAY_ONLY`) — chỉ `apply_snapshot` (server response) ghi, **không** mutator chân lý, đọc trả bản sao, `source()`/`is_offline()` nhãn cache-vs-server, persist snapshot offline-view, phát `state_refreshed`. Mutation: `Feature/UI → NetworkClient → Server → response → StateCache`. gdUnit4 toàn bộ 38/38 pass (0 orphan).

- [`0016-auth-jwt-guest-standardized.md`](0016-auth-jwt-guest-standardized.md) — auth guest JWT (Phase 18): `Account` (`Domain/Accounts/`, `AggregateRoot<Guid>`, `AccountType.Guest`, raise `AccountCreated`) = ranh giới định danh state server-authoritative; guest login `POST /api/v1/auth/guest` → `CreateGuestAccountCommand` → JWT qua port `ITokenService` (JWT **chỉ** ở Infrastructure: `JwtTokenService` HS256 + `JwtOptions`); endpoint nghiệp vụ **auth mặc định** (`FallbackPolicy=RequireAuthenticatedUser`), public whitelist `.AllowAnonymous()`; key từ secret/env `Jwt__SigningKey` (fail-fast, không hardcode/log). Provider linking = Post-MVP.
- [`0017-profile-persistence-standardized.md`](0017-profile-persistence-standardized.md) — profile / save root (Phase 19): `PlayerProfile` (`Domain/Profiles/`, `AggregateRoot<Guid>`, 1-1 với `Account`) = **gốc save server-authoritative** (ADR-007) mà feature state sau **mở rộng**; `GET /api/v1/profile` → `GetOrCreateProfileCommand` (get-or-create + read-repair migrate, atomic), read thuần `GetMyProfileQuery`; ownership **chỉ** từ token `sub` qua port `ICurrentUser` (adapter `Api/Auth/CurrentUser.cs`); repo `IPlayerProfileRepository`; bảng `player_profiles` **unique index `account_id`** + FK→`accounts` = **idempotency ở tầng DB** (không check-then-insert), guest login tạo account+profile cùng transaction (eager); **versioning** `schema_version` per-row + `PlayerProfile.Upgrade()` (`v(N)→v(N+1)`, test preservation) ≠ EF DDL migration. Mọi mutation qua command server.
