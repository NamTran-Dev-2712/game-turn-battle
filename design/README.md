# `design/` — Tài liệu/nguồn thiết kế làm việc

> **Lưu ý (SSOT):** `design/` **không** có trong `docs/architecture/project-structure.md` §2 — đây là thư mục **bổ sung** theo yêu cầu bootstrap (được ghi nhận trong `docs/audit/bootstrap-audit.md`). Nguồn sự thật thiết kế game vẫn là `docs/mvp/`.

| Mục | Nội dung |
|---|---|
| **Purpose** | Nơi làm việc cho tài sản thiết kế thô: mockup UX, sơ đồ, bảng cân bằng nháp, ghi chú thiết kế. |
| **Responsibilities** | Chứa bản nháp/tham khảo — **không** phải quyết định chính thức. |
| **Allowed** | Mockup, hình sơ đồ, bảng nháp, ghi chú. |
| **Not allowed** | ❌ thay thế SSOT `docs/mvp/`; ❌ số cân bằng chính thức (đó là `config/`). |
| **Dependencies** | Tham chiếu `docs/mvp/`. |
| **Owner** | Game design team. |
| **Future expansion** | Có thể tách kho asset thiết kế riêng nếu phình to. |
