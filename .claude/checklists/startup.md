# Checklist: Session Startup

Run once at the start of a work session, before touching code.

- [ ] Read `CLAUDE.md` §2 Golden Rules (loaded automatically — confirm you're applying them).
- [ ] Know the current phase/milestone: skim `docs/audit/bootstrap-audit.md` + `docs/roadmap/README.md`.
- [ ] Have the task's **goal + acceptance criteria** in hand. If vague, clarify before starting.
- [ ] Identify the scope: backend / client / config / combat → open the matching `.instructions/` hint.
- [ ] Check `.tasks/` for a relevant hand-off from a previous session.
- [ ] Confirm you're on a feature branch, not `main`.
